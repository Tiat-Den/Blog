# Beyond Streaming: Interaction and Processing

While streaming a video is great, the true potential of modern media apps lies in interaction. In the Flutter Movie App, I wanted to move beyond passive consumption and introduce active user engagement. This led to the integration of two powerful, yet complex, tools: Agora for Real-Time Communication (RTC) and FFmpeg for on-device video processing.

## Real-Time Watch Parties with Agora RTC

Imagine watching a movie and being able to react with your friends in real-time. This requires extremely low latency audio and video routing. I chose `agora_rtc_engine` for this task.

Integrating Agora involves initializing an engine, managing channels, and handling complex UI states for local and remote video rendering.

### The Setup

First, initialize the engine using your Agora App ID:

```dart
import 'package:agora_rtc_engine/agora_rtc_engine.dart';
import 'package:permission_handler/permission_handler.dart';

late RtcEngine _engine;

Future<void> initAgora() async {
  // Request permissions first!
  await [Permission.microphone, Permission.camera].request();

  // Create the engine
  _engine = createAgoraRtcEngine();
  await _engine.initialize(const RtcEngineContext(
    appId: "YOUR_AGORA_APP_ID",
    channelProfile: ChannelProfileType.channelProfileCommunication,
  ));

  // Register event handlers
  _engine.registerEventHandler(
    RtcEngineEventHandler(
      onJoinChannelSuccess: (RtcConnection connection, int elapsed) {
        print("Joined channel: ${connection.channelId}");
      },
      onUserJoined: (RtcConnection connection, int remoteUid, int elapsed) {
        // Update UI to show the new user
      },
      onUserOffline: (RtcConnection connection, int remoteUid, UserOfflineReasonType reason) {
        // Remove user from UI
      },
    ),
  );

  // Enable video and join
  await _engine.enableVideo();
  await _engine.joinChannel(
    token: "YOUR_TEMP_TOKEN",
    channelId: "movie_room_1",
    uid: 0, 
    options: const ChannelMediaOptions(),
  );
}
```

<Callout type="warning">
  Permissions are critical here. You must use `permission_handler` to explicitly request camera and microphone access, especially on iOS where strict privacy policies apply.
</Callout>

## On-Device Processing with FFmpeg

Sometimes, you need to manipulate video locally before uploading or sharing—perhaps creating a quick clip from a trailer or compressing a file. `ffmpeg_kit_flutter_new` brings the power of FFmpeg to mobile.

### Executing Commands

FFmpeg operates via command-line strings, which the Flutter package executes natively:

```dart
import 'package:ffmpeg_kit_flutter_new/ffmpeg_kit.dart';
import 'package:ffmpeg_kit_flutter_new/return_code.dart';

Future<void> compressVideo(String inputPath, String outputPath) async {
  // A basic command to compress a video
  String command = "-i $inputPath -vcodec libx264 -crf 28 $outputPath";

  final session = await FFmpegKit.execute(command);
  final returnCode = await session.getReturnCode();

  if (ReturnCode.isSuccess(returnCode)) {
    print("Video compressed successfully!");
  } else {
    print("Compression failed.");
  }
}
```

<Callout type="tip">
  FFmpeg operations block the UI if not handled carefully. Fortunately, `FFmpegKit.execute` runs asynchronously, but be aware of the intense CPU usage on the device!
</Callout>
