## Hypothesis

We can create a highly performant background grid using only CSS `linear-gradient` and `background-size`, avoiding the DOM overhead of SVGs or Canvas elements.

## Attempts

1. **First Attempt**: Used `repeating-linear-gradient`. This caused jagged edges on non-retina displays.
2. **Second Attempt**: Used standard `linear-gradient` with `background-size`. Much better antialiasing.

```css
.grid-bg {
  background-size: 40px 40px;
  background-image: 
    linear-gradient(to right, rgba(255, 255, 255, 0.05) 1px, transparent 1px),
    linear-gradient(to bottom, rgba(255, 255, 255, 0.05) 1px, transparent 1px);
}
```

## Result

The resulting grid is extremely lightweight and scales perfectly. 

## Lessons Learned

CSS gradients are hardware accelerated and almost always faster than SVGs for simple geometric patterns like grids or dots. The key to crisp lines is ensuring the transparent stop happens exactly at the 1px mark.
